## 3.0 历史基线：已执行

- 服务端 7 项状态/凭据/导出/回滚测试通过。覆盖独立玩家地址与凭据、个人 ZIP 不含服务器地址或网络主密钥、撤销不影响其他玩家、防火墙只移除本工具新增端口、安装失败状态可恢复。
- PowerShell 7.5 解析和内嵌 C# 编译通过。覆盖首次设置空白、中文昵称和 TOML 转义、旧版配置拒绝、仅虚拟网段路由、不写默认路由/DNS、实际直连/中继显示、重连不重复校验复制组件。
- 在一次性 Linux 容器中运行原版 EasyTier 2.6.4，建立两个独立 NAT 命名空间。UDP 使用稳定端口映射，入站由 conntrack 过滤；独立套接字探测也通过，证明测试拓扑支持 UDP 打洞。STUN 使用隔离的 RFC5389 绑定响应器。
- 两个独立凭据客户端、无固定入站监听，在两个 NAT 后通过打洞建立 1 跳直连。
- 直连 UDP 62056 往返 200 次通过。虚拟网段广播、255.255.255.255 广播到 UDP 62900 均收到另一端响应。
- 主动阻断两端公网间通路，观察到两端变成 2 跳中继；等待路径和安全握手完成后，中继 UDP 往返 100 次及广播通过。
- 两次完整测试的断链至中继数据恢复分别约 12.57 秒、14.51 秒。期间有丢包，不承诺无缝切换。
- 解除阻断后恢复 1 跳直连，继续收发通过。两端默认路由与连接前一致。
- 虚拟网段的 UDP 保持可达，同时 TCP 监听端口无法连接，符合当前游戏网段 ACL。
- 在线撤销一名玩家后，其路由与游戏数据失效，另一名玩家仍保持服务器连接。未签发的新密钥无法接入。
- 服务端已部署到目标 CentOS 7、3.10.0 内核，systemd 服务 active，原有防火墙、审计、SSH 服务保持 active。服务不创建 TUN，系统网卡仍只有 eth0、lo。初始空闲进程常驻内存约 30 MiB；5 秒空闲抽样 CPU 约 0.2%（按单核计），不代表游戏负载性能。
- 目标机器的 51820/UDP 原生发包没有到达，9527/UDP 可以到达；服务已迁移至 TCP/UDP 9527，保留现有凭据，移除本工具新增的旧端口规则。
- 公网实测：两个独立凭据客户端强制关闭 P2P，经真实部署服务器中继。UDP 外层通路中每包 494 字节，正向 20 次往返约 1.653 秒，反向 20 次往返约 1.649 秒；路由确认 2 跳。该结果只证明测试链路的收发，不能推算多人对局容量。
- 六人复核：六个独立 NAT、15 对玩家，覆盖部分回退、全部回退和恢复直连；另测六个真实公网中继客户端的稳定负载、过载及降载恢复。详细 RTT、丢包、切换时间、带宽和边界见 [六人测试记录](six-player-test.md)，附非敏感原始结果 JSON。这仍是网络测试，没有启动六个文明6游戏实例。

## 测试范围

Linux 测试使用真实二进制、真实虚拟网卡和 UDP 数据包，未模拟选路结果。
此测试拓扑不能代表所有运营商 NAT 或防火墙；不可穿透时应保持中继。
200 次直连收发约 0.034 秒、100 次中继收发约 0.024 秒来自本机隔离环境，不代表公网延迟或 1 Mbps 服务器承载人数。
桌面状态刷新只读路由，每 5 秒一次。组件哈希仅首次安装、升级或主动“检查组件”执行；导出个人 ZIP 复用预压缩模板，避免每人重新压缩程序。

## 公网 TCP 限制

- 服务器本机 TCP 独立凭据认证通过；公网 TCP 测试客户端握手超时。
- 原生主机与 Docker 对照探测中，9527/TCP 应用数据均未到达服务器，9527/UDP 控制包可以到达。当前只确认公网 UDP 中继成功，不能宣称公网 TCP 回退已通过。
- 经用户明确授权，另起了最多 95 秒的 TCP443 认证测试进程，不重启生产服务、不修改防火墙。已确认临时监听启动，但公网客户端仍握手超时，未建立中继路径。临时进程按时停止，生产服务保留在 9527。
- 公网测试凭据已撤销，临时容器已删除。

## 复现

```bash
python3 -m unittest discover -s tests -p test_relay.py -v
# 准备 .build/client-test.toml（PowerShell 容器内）：
pwsh -NoProfile -File tests/client.Tests.ps1 -ConfigOutput /workspace/.build/client-test.toml
# 在含 iproute2、iptables、ping 的一次性特权测试容器内，以 /workspace 挂载本仓库：
python3 -u tests/network_integration.py
# 六人、独立 NAT、受控延迟与 1Mbps 中继：
python3 -u tests/six_player_network.py
```

网络测试只在一次性测试容器运行，所有防火墙和转发设置限于其命名空间；生产服务器无需开启转发或 NAT。
