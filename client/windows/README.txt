核平联机助手 1.0.0
适用于 Windows 10/11 x64

开始联机
1. 完整解压 ZIP，双击 Civ6Relay.exe，允许管理员权限。
   请在解压后的文件夹启动，保留同目录的其他文件。
2. 填写自己的“玩家昵称”、本次联机使用的“服务器地址”和“端口”，点击“连接网络”。
   支持中文昵称，设置会保存在本机；修改后请断开再连接。
3. 所有玩家连接后，在文明6中选择“多人游戏 → 局域网”。
4. 一人创建房间，其他人刷新局域网列表并加入。玩完点击“断开连接”。

Key 接入
服务器提供 Key 接入时，填写地址和接入端口，点击“获取 Key”。
获取后可点击“复制”；联机玩家请填写同一个 Key。
已有 Key 可直接填入再连接。不需要 Key 的服务器可留空连接；
主动获取时会提示“此服务器无需 Key。”。
使用服务器专用 ZIP 时，继续填写搭建者提供的原组网端口直接连接。

查看连接和日志
桌面界面支持窗口缩放，连接设置、玩家列表和日志分区显示。
通过左侧导航切换“联机大厅”“运行日志”和“设置”。
玩家列表显示玩家、虚拟 IP、直连或中继路径及实时延迟。
连接期间每 10 秒更新组网房间数量、服务器 CPU、内存和上下行速率。
组网房间对应虚拟局域网，Key 模式下每个有效 Key 对应一个房间。
“实时延迟”测量到玩家的延迟；Ping 无回应不等于游戏不通。中继时，“链路延迟”只到中继节点。
“运行日志”记录连接、路径变化和错误，可选中文字复制，也可点击“复制”或“导出日志”。
需要排查时，在“设置 → 网络诊断”中点击“开始诊断”，复制完整结果。

切换主题
在“设置 → 外观”选择“黑白”或“文明6”，立即生效并自动保存。
文明6主题使用深灰蓝、柔和金色和羊皮纸配色；重启后沿用上次选择。

关闭窗口
默认勾选“关闭窗口时自动断开连接”。取消勾选后，关闭窗口会保留当前连接；再次打开可查看状态或断开。

版本与更新
在“设置 → 关于与更新”查看客户端版本。
GitHub：https://github.com/FLF-Gamer/civ6-relay
点击“下载新版”打开 Releases。更新前先断开，再完整解压新版客户端。
点击“查询服务端版本”查询大厅填写的服务器地址和 HTTP 接入端口，
不需要昵称或 Key，也可在联机期间查询。原组网端口不提供该接口。
服务器未提供版本查询接口时会显示提示，不会影响现有连接。

常见问题
- 看不到玩家：确认双方都已连接，服务器 IP 和端口相同。
- 看不到房间：确认选择了“局域网”，双方游戏版本、DLC 和模组一致，并允许文明6通过 Windows 防火墙。
- 提示组件缺失或损坏：先断开，再到设置中点击“检查组件”；更新客户端时请完整解压新版。
- 仍无法联机：复制“网络诊断”结果和运行日志，提供给维护者。

游戏优先使用玩家直连，无法直连时使用服务器中继；普通上网和下载继续走本地网络。
