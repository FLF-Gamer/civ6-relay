文明6联机助手 3.3.0
适用于 Windows 10/11 x64

开始联机
1. 完整解压 ZIP，双击 Civ6Relay.exe，允许管理员权限。
   请在解压后的文件夹启动，保留同目录的其他文件。
2. 填写自己的“玩家昵称”、本次联机使用的“服务器 IP”和“端口”，点击“连接”。
   支持中文昵称，设置会保存在本机；修改后请断开再连接。
3. 所有玩家连接后，在文明6中选择“多人游戏 → 局域网”。
4. 一人创建房间，其他人刷新局域网列表并加入。玩完点击“断开”。

查看连接和日志
“网络状态”显示玩家、虚拟 IP、直连或中继路径及实时延迟。
“延迟（Ping）”测量到玩家的延迟；Ping 无回应不等于游戏不通。中继时，“链路延迟”只到中继节点。
“运行日志”记录连接、路径变化和错误，可选中文字复制，也可点击“复制日志”或“导出日志”。
需要排查时点击“网络诊断”，在结果框按 Ctrl+A、Ctrl+C 复制完整结果。

关闭窗口
默认勾选“关闭窗口时自动断开”。取消勾选后，关闭窗口会保留当前连接；再次打开可查看状态或断开。

常见问题
- 看不到玩家：确认双方都已连接，服务器 IP 和端口相同。
- 看不到房间：确认选择了“局域网”，双方游戏版本、DLC 和模组一致，并允许文明6通过 Windows 防火墙。
- 提示组件缺失或损坏：先断开，再点击“检查组件”；更新客户端时请完整解压新版。
- 仍无法联机：复制“网络诊断”结果和运行日志，提供给维护者。

游戏优先使用玩家直连，无法直连时使用服务器中继；普通上网和下载继续走本地网络。
